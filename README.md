# mvc_base
Projet de cours structure minimal MVC POO routing
### 1 cloner le projet 
```sh
git clone https://github.com/mithridatem/mvc_base
cd mvc_base
```

### 2 installer l'autoload
```
composer install
```

### 3 démarrer le projet
```sh
php -S 127.0.0.1:8000 -t public
```
### 4 accéder au projet avec l'url:
`http://127.0.0.1:8000`
